# Course 課表 — 模式與區塊顯示規格

## 整體版面區塊

```
┌──────────────────────────────────┐
│           標題列 (title-bar)      │
├──────────────────────────────────┤
│  格子區 (grid-wrap)  │ 早午晚欄   │
│                      │ (time-col) │
├──────────────────────────────────┤
│  下方按鈕列 (btn-row)             │
└──────────────────────────────────┘
```

---

## 格子區 (grid-wrap)

### 標頭列（星期）
- 顯示：一 二 三 四 五
- 所有模式下外觀相同
- **個人空閒模式**：停用點擊（點了不切換日期）
- **其他模式**：點擊切換該日選取狀態（outer 模式）

### 左欄（節次）
- 顯示：1～10、A～D
- 所有模式下外觀相同
- **個人空閒模式**：停用點擊
- **其他模式**：點擊切換該節選取狀態（outer 模式）

### 右側欄 早/午/晚
- 顯示：早（1-4）、午（5-10）、晚（A-D）
- **個人空閒模式**：停用點擊
- **其他模式**：點擊切換整組節次選取狀態

### T 按鈕（左上角）
- 所有模式下行為相同：切換時間條顯示
- 時間條：跨欄顯示「第N節 HH:MM ~ HH:MM」

## 課表格子 (cell--slot) — 各模式顯示

### 模式一：自由點擊模式（inner mode）
**觸發條件**：點擊課表格子
| 狀態 | 背景色 | 格子內容 |
|------|--------|---------|
| 未選 | 暗色 | 空白 |
| 已選（無老師篩選） | 青色發光 | 空白 |
| 已選（有老師篩選） | 青色發光 | 老師縮寫方格（有課=亮，無課=暗） |

### 模式二：外框選取模式（outer mode）
**觸發條件**：點擊星期/節次/早午晚
| 狀態 | 背景色 | 格子內容 |
|------|--------|---------|
| 未在選取範圍 | 暗色 | 空白 |
| 在選取範圍（無老師篩選） | 青色發光 | 空白 |
| 在選取範圍（有老師篩選） | 青色發光 | 老師縮寫方格（有課=亮，無課=暗） |

### 模式三：依老師搜尋
**觸發條件**：蓋層選「依老師」→ 選某位老師
| 狀態 | 背景色 | 格子內容 |
|------|--------|---------|
| 該老師沒課 | 暗色 | 空白 |
| 該老師有課 | 青色強發光 | 課程名稱（粗體）、教室、班級縮寫 |
| 有課且含選修 | 青色強發光 | 課程名稱（粗體）、教室、班級縮寫、左上角 ★ |

### 模式四：依班級搜尋
**觸發條件**：蓋層選「依班級」→ 選某班
| 狀態 | 背景色 | 格子內容 |
|------|--------|---------|
| 該班沒課 | 暗色 | 空白 |
| 該班有課 | 青色強發光 | 課程名稱（粗體）、老師、教室 |
| 有課且含選修 | 青色強發光 | 課程名稱（粗體）、老師、教室、左上角 ★ |

### 模式五：依教室搜尋
**觸發條件**：蓋層選「依教室」→ 選某教室
| 狀態 | 背景色 | 格子內容 |
|------|--------|---------|
| 該教室無課 | 暗色 | 空白 |
| 該教室有課 | 青色強發光 | 課程名稱（粗體）、老師、班級縮寫 |
| 有課且含選修 | 青色強發光 | 課程名稱（粗體）、老師、班級縮寫、左上角 ★ |

### 模式六：個人空閒模式 ← 新增
**觸發條件**：蓋層選「個人空閒」→ 選某位老師
| 格子顏色狀態 | 背景色 | 格子內容 |
|------------|--------|---------|
| 無色（值=0） | 暗色（預設） | 若為老師上課時段：顯示「上課」文字 |
| 黃色（值=1） | 黃色半透明 | 若為老師上課時段：顯示「上課」文字 |
| 紅色（值=2） | 紅色半透明 | 若為老師上課時段：顯示「上課」文字 |

**點擊行為**：
- 所有格子皆可點擊：無色(0) → 黃(1) → 紅(2) → 無色(0)
- 進入模式時：老師上課格自動設為紅色(2)，其餘為無色(0)
- 「上課」文字：只要該時段是選定老師的上課時間就顯示，不受顏色影響

**停用行為**：
- 星期/節次/早午晚 欄位點擊無效（不切換模式）
- 搜尋/選修星星/縮寫 等內容不顯示

## 下方按鈕列 (btn-row)

| 按鈕 | 顯示文字 | 行為 |
|------|---------|------|
| 左按鈕（清空/全選） | 有選取時→「清空」；無選取→「全選」 | 清空：清除所有選取與模式；全選：outer 模式全選所有日/節 |
| 中間標籤（模式名稱） | 見下表 | 點擊開啟蓋層 |
| 右按鈕（詳細） | 詳細 | 開啟詳細蓋層（無選取時無效） |

**中間標籤文字**：
| 模式 | 文字 | 顏色 |
|------|------|------|
| 自由點擊 | 點擊格模式 | 紫色 |
| 依老師 | 老師模式－姓名 | 青色 |
| 依班級 | 班級模式－縮寫 | 綠色 |
| 依教室 | 教室模式－教室 | 橘色 |
| 個人空閒 | 個人空閒－姓名 | 橘黃色 |

---

## 搜尋蓋層 (overlay)

五個 tab，各自的列表：

| Tab | 內容 | 選取後 |
|-----|------|--------|
| 自由 | 無列表 | 清空所有，回到自由點擊模式 |
| 依老師 | 所有老師名稱按鈕 | 進入依老師搜尋模式 |
| 依班級 | 依年級分組的班級按鈕 | 進入依班級搜尋模式 |
| 依教室 | 所有教室按鈕 | 進入依教室搜尋模式 |
| 個人空閒 | 所有老師名稱按鈕 | 進入個人空閒模式，初始化老師上課格為紅色 |

---

## 詳細蓋層 (detail-overlay)

- **個人空閒模式下**：詳細按鈕點擊 → 暫不支援（或可顯示空閒摘要，待定）
- **其他模式**：顯示選取時段的課程清單（含排序）

---

## 模式互斥規則

同時只能有一個模式啟動。切換模式時，前一個模式的資料清空：

| 切換到 | 清空 |
|--------|------|
| 自由點擊 | searchMode、searchValue、freeTeacher、freeCells、selDays、selPeriods、active |
| 依老師/班級/教室 | active、selDays、selPeriods、freeTeacher、freeCells |
| 個人空閒 | active、selDays、selPeriods、searchMode、searchValue |
| 清空按鈕 | 全部清空，mode=null |
