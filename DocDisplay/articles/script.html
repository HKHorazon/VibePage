成果報告講稿

2026-05-19

第一段：HTML

我們這次學習的第一個技術是 HTML。HTML 的工作是決定網頁上「有什麼東西」，就像蓋房子要先有樑柱，HTML 就是整個網頁的骨架。我們學會用標籤定義標題、段落、清單和按鈕，在我們的專案裡，HTML 幫我們搭好了遊戲的舞台，包含畫面顯示的區塊和讓玩家操作的按鈕。沒有 HTML 打底，後面的 CSS 和 JavaScript 都沒有地方可以附著。

第二段：CSS

學完骨架之後，我們接著學習 CSS。CSS 負責網頁的「外觀」，決定每個元素長什麼樣子、放在哪裡。我們用 CSS 設定了遊戲的配色、字體大小，以及讓畫面填滿手機螢幕的版面設定。我們也學到了 Flexbox，可以輕鬆把元素排到想要的位置，還加了按鈕的顏色變化效果，整體質感提升了很多。

第三段：JavaScript

最後是 JavaScript，也是三個技術裡最複雜的。JavaScript 是網頁的「大腦」，負責所有的邏輯和互動。HTML 和 CSS 都是靜態的，要讓遊戲真正動起來一定要靠 JavaScript。我們學會了變數、函式和事件監聽，讓遊戲能偵測玩家的觸控操作。最核心的是「遊戲迴圈」，讓程式每秒重複執行，不斷更新物件位置並重新繪製畫面，遊戲才會流暢運作。

第四段：AI 實作

我們知道 AI 可以直接做出這些東西，但老師說要先了解基礎才能真的用得起來，所以我們在學完之後，試著用 ChatGPT 製作了三款手機網頁小遊戲。過程中我們主要是用說的告訴 AI 想要什麼效果，AI 會幫我們生出程式碼，我們再貼上去看看有沒有動。雖然很多程式碼我們還是看不太懂，但大概知道每個部分是在做什麼。最後老師把我們的成果放到網路上，現在用手機就可以直接玩到我們自己做的遊戲。
