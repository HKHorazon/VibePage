Antigravity 的使用說明

2026-05-26

以下是 Antigravity 為我們產出的 Face AR 配件功能完整操作說明，包含一鍵設定、模型替換與手機建置三個步驟。

第一步：一鍵完成場景與 Prefab 設定

  1. 回到 Unity 編輯器，等待專案完成編譯。
  2. 在頂部選單列，點選 Tools > Face AR > Setup Scene & Prefab。
  3. 系統將自動完成以下工作：
    • 偵測場景中的 ARFaceManager
    • 在 Assets/Prefabs/ 生成 ARFaceAccessories.prefab
    • 在 Assets/Materials/ 生成 3D URP 材質，避免 Placeholder 出現粉紅色（材質遺失）
    • 自動將 Prefab 指派給 ARFaceManager
    • 建立深色半透明 UI Canvas、ScrollRect 選單，以及 FaceAccessoryUI 控制器
    • 建立適合專案輸入系統（新版或舊版 Input System）的 EventSystem
  4. 出現「Face AR Setup Complete」對話視窗時，點擊 OK。

第二步：更換 3D 模型與調整位置

本系統使用 Unity 標準的階層（Hierarchy）架構定位配件，不需寫程式，直接在編輯器拖曳即可：

  1. 在 Project Window 找到並雙擊 Assets/Prefabs/ARFaceAccessories.prefab 進入 Prefab 編輯模式。
  2. 展開 Accessories 子節點，看到三個錨點：
    • Accessory_Hat：帽子錨點（預設紅色扁圓柱 Placeholder）
    • Accessory_Glasses：眼鏡錨點（預設藍綠色鏡框方塊）
    • Accessory_Mustache：鬍子錨點（預設棕色膠囊體）
  3. 將你的 3D 模型（.fbx、.obj 或 Prefab）拖曳到對應錨點下成為子物件，並刪除或隱藏原 Placeholder。
  4. 使用 W（移動）、E（旋轉）、R（縮放）工具調整位置。
Prefab 根節點 (0, 0, 0) 是臉部中心（約兩眼之間），以此為基準調整：帽子往上、眼鏡往前、鬍子往下。
  1. 點擊 Prefab 視窗左上角的 < 儲存並退出 Prefab 編輯模式。

第三步：手機測試與建置

  1. 前往 Edit > Project Settings > XR Plug-in Management，確認已勾選對應平台：
    • Android → Google ARCore
    • iOS → Apple ARKit
  2. 前往 Build Settings，將 AR 場景加入 Build 列表。
  3. 連接手機，點擊 Build And Run。
  4. 開啟 App 並授予相機權限，對準人臉，即可透過底部滾動按鈕切換配件。

程式碼檔案一覽

檔案用途
FaceAccessoryController.cs控制單一臉部 Prefab 上的配件開關
ARFaceAccessorySceneManager.cs監聽臉部追蹤事件，同步多臉追蹤狀態與選定配件
FaceAccessoryUI.cs動態產生按鈕，提供毛玻璃質感與縮放過渡微動畫
FaceARSceneSetup.cs編輯器腳本：一鍵產生 Prefab、URP 材質並建立 UI 綁定
