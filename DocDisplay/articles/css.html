CSS：網頁的外觀

2026-05-19

CSS 寫在哪裡

通常獨立一個 .css 檔案，再用 <link> 引入 HTML。

<!-- 在 HTML 的 <head> 裡加這行 -->
<link rel="stylesheet" href="style.css">

選擇器語法

選擇器決定「要改哪個元素」，大括號內是要套用的樣式。

/* 標籤選擇器 */
p {
  color: #333;
}

/* class 選擇器 */
.card {
  background: white;
  border-radius: 8px;
}

/* id 選擇器 */
#title {
  font-size: 2rem;
}

顏色與背景

body {
  background-color: #f0f0f0;
  color: #1a1a1a;
}

.highlight {
  background: linear-gradient(to right, #3b82f6, #06b6d4);
  color: white;
}

字體與文字

h1 {
  font-size: 2rem;
  font-weight: 700;
  letter-spacing: -0.02em;
}

p {
  font-size: 1rem;
  line-height: 1.8;
  text-align: center;
}

尺寸與間距

margin 是外距，padding 是內距。

.box {
  width: 300px;
  height: 200px;
  margin: 16px;       /* 外距，推開周圍元素 */
  padding: 24px;      /* 內距，內容與邊框的距離 */
}

Flexbox 排版

最常用的現代排版方式，讓子元素自動對齊。

.container {
  display: flex;
  justify-content: center;   /* 水平置中 */
  align-items: center;       /* 垂直置中 */
  gap: 16px;                 /* 子元素間距 */
}

/* 讓畫面填滿整個視窗 */
.fullscreen {
  width: 100vw;
  height: 100vh;
}

互動效果

:hover 在滑鼠移上去時套用，transition 讓變化有動畫感。

.btn {
  background: #3b82f6;
  color: white;
  padding: 12px 24px;
  border-radius: 8px;
  transition: background 0.2s;
}

.btn:hover {
  background: #2563eb;
}
