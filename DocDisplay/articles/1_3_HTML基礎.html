HTML：網頁的骨架

2026-05-19

基本文件結構

每一個 HTML 檔案都從這個骨架開始。

<!DOCTYPE html>
<html lang="zh-Hant">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的網頁</title>
</head>
<body>
  <!-- 內容放這裡 -->
</body>
</html>

標題與段落

標題有六個層級，<h1> 最大，<h6> 最小。

<h1>主標題</h1>
<h2>副標題</h2>
<h3>小標題</h3>

<p>這是一個段落，可以放一般文字內容。</p>

清單

無序清單用 <ul>，有序清單用 <ol>，項目都是 <li>。

<ul>
  <li>蘋果</li>
  <li>香蕉</li>
  <li>橘子</li>
</ul>

<ol>
  <li>第一步</li>
  <li>第二步</li>
  <li>第三步</li>
</ol>

連結與圖片

<a> 建立超連結，<img> 插入圖片。

<a href="https://www.google.com">前往 Google</a>

<img src="photo.jpg" alt="一張照片">

區塊容器

<div> 是最常用的容器，用來包住一組元素方便統一管理。

<div class="card">
  <h2>卡片標題</h2>
  <p>卡片內容說明文字。</p>
</div>

按鈕與輸入

<button>點我</button>

<input type="text" placeholder="請輸入文字">

<input type="number" placeholder="請輸入數字">

畫布（Canvas）

製作互動動畫或遊戲時使用，JavaScript 負責在上面繪圖。

<canvas id="myCanvas" width="400" height="300"></canvas>
