# 手機網頁小遊戲製作基礎：從零開始的開發指南

---

## 1. HTML：遊戲的骨架與結構
**HTML (HyperText Markup Language)** 是所有網頁的基石。如果把一個遊戲比喻成一棟建築，HTML 就是這棟建築的「樑柱」與「牆壁」。它負責定義網頁上出現的內容是什麼。在開發小遊戲時，HTML 的作用是建立一個「舞台」，我們通常會使用 `<canvas>`（畫布）標籤，這就是遊戲畫面真正「發生」的地方。

### 核心概念與範例
想像你在寫一張清單給瀏覽器，告訴它畫面需要哪些組件。你不需要處理顏色或動作，只需要確保每個組件都「各就各位」。
* **遊戲畫布**：`<canvas id="gameCanvas"></canvas>`。這是最重要的標籤，所有的角色（小鳥、管子）都會由 JavaScript 在這塊畫布上繪製。
* **資訊顯示**：`<div id="score">Score: 0</div>`。這行程式碼會在畫面上準備一個區域來顯示數字。
* **介面按鈕**：`<button id="startBtn">開始遊戲</button>`。定義一個讓玩家互動的觸發點。

對於完全不了解網頁製作的人來說，HTML 的學習重點在於「層級結構」。當你透過 AI 輔助時，你會請它建立一個包含遊戲畫布的檔案，AI 會幫你把這些標籤排列整齊，讓後續的視覺美化與程式邏輯有地方可以依附。

---

## 2. CSS：遊戲的皮囊與視覺包裝
**CSS (Cascading Style Sheets)** 負責的是「美學」與「佈局」。如果 HTML 是骨架，CSS 就是皮膚、衣服與化妝。在手機網頁遊戲中，CSS 的重要性不亞於程式碼，因為它決定了遊戲在不同手機尺寸下是否能美觀地呈現，並確保玩家的操作按鈕處於容易點擊的位置。

### 核心概念與範例
假設你的 HTML 有一個畫布，但它現在縮在螢幕左上角，小到看不見。這時你需要 CSS 來下達樣式指令：
* **全螢幕佈局**：`canvas { width: 100vw; height: 100vh; }`。這代表讓遊戲畫布的寬度與高度「百分之百」填滿手機的視覺視窗（vw/vh 代表視窗單位）。
* **背景美化**：`body { background: linear-gradient(to bottom, #87CEEB, #E0F6FF); }`。這能讓原本死白的背景，瞬間變成像 Flappy Bird 那樣由淺藍到深藍的天空漸層色。
* **文字樣式**：`#score { font-family: 'Arial'; color: white; font-size: 24px; }`。讓得分文字變得大而醒目。

透過 AI 的幫助，你可以下達如「請讓背景變成夜晚模式」或「讓分數文字帶有黑邊陰影」等描述，AI 會生成對應的 CSS 語法，讓原本陽春的網頁瞬間具備專業遊戲的質感。

## 3. JavaScript：遊戲的大腦與靈魂
**JavaScript (JS)** 是最關鍵的部分，它是網頁的程式語言，負責「動作」與「邏輯」。沒有 JavaScript，你的遊戲就只是一張不會動的靜態網頁。在 Flappy Bird 的例子中，所有的物理現象——包含小鳥受重力下降、玩家點擊後向上跳躍、以及最核心的「碰撞偵測」——全都是由 JavaScript 驅動的。

### 核心概念與範例
JavaScript 的運作就像是一連串的「如果...就...」邏輯判斷。它會以極快的速度（通常每秒 60 次）不斷計算並重新繪製畫面。
* **物理重力**：`bird.y += 2;`。這代表每一毫秒，小鳥的垂直座標（y）就增加 2 像素，視覺上小鳥就會一直往下掉。
* **觸控互動**：`window.addEventListener('touchstart', jump);`。這告訴手機，一旦玩家的手指「碰到（touchstart）」螢幕，就執行「跳躍（jump）」這個動作。
* **勝負判定**：`if (bird.y > canvas.height) { alert('Game Over'); }`。這代表「如果小鳥的位置超過了畫布的高度（掉出螢幕外），就跳出遊戲結束的訊息」。

它是賦予遊戲生命力的引擎，負責處理所有的遊戲規則、隨機障礙物的產生以及分數的加總計算。

## 4. 小遊戲製作：整合與開發流程
**小遊戲製作** 是將上述三種技術融合在一起的藝術。製作一個可運作的手機網頁遊戲，其核心流程包含「遊戲迴圈」（Game Loop）的建立。這是一個永不停止的循環，持續偵測玩家的輸入並更新遊戲狀態。

### 開發流程範例
在實際製作時，AI 會幫你把 HTML、CSS、JS 整合。一個典型的 AI 協作製作流程如下：
1. **建立環境**：先請 AI 給你一個基本的 HTML5 模板，確保能在手機瀏覽器開啟。
2. **物件定義與初始化**：定義「小鳥」與「管子」的數據。例如小鳥的初始位置 `(x: 50, y: 100)` 與大小。
3. **實作遊戲動力學**：利用 `Math.random()` 讓管子從螢幕右方以隨機的高度規律出現。
4. **手機優化**：針對手機觸控進行優化。例如設定「點擊螢幕任何地方都能跳躍」，這比點擊特定的小按鈕更適合單手操作。

透過 AI 協作，即使你不了解複雜的語法，只要能清晰地描述這些邏輯步驟（例如：每過一根管子得一分、撞到管子就結束並震動），AI 就能將這些指令組合成一個完整的遊戲檔案，讓你在手機上直接運行。
