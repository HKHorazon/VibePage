前言

Antigravity 是 Google 推出的 Agent AI 開發工具。它的介面和你可能聽過的 VS Code（一款廣泛使用的程式編輯器）長得幾乎一模一樣——但它不只是編輯器，而是一個以 AI 代理為核心的操作平台：你說目標，AI 自己規劃步驟、執行任務、甚至修正錯誤。

簡單說：VS Code 是「你寫程式的地方」，Antigravity 是「你下指令、AI 幫你寫程式的地方」。


下載與安裝

前往官網 antigravity.google，下載對應你電腦系統的安裝檔（Windows / Mac / Linux），執行後照步驟安裝即可。安裝完成後，用 Google 帳號登入。

費用方面：有免費公測額度，超出後需使用 Google AI Credits 購買點數。如果你已有 Google One 或 Gemini Advanced 訂閱，部分額度會直接整合進去。

Antigraviy 有兩個介面，正上方的Open Agent Manager / Open Editor 可開啟另一個介面。


介面一：Editor（編輯器）

打開 Antigravity 後，你看到的主畫面就是 Editor。外觀和 VS Code 幾乎相同——左側是檔案列表，中間是主要工作區，右側可以開側邊欄。

和 VS Code 不同的地方在於，這裡有一個對話輸入框，你可以直接用自然語言告訴 AI 你想做什麼，例如：「幫我建一個可以記錄待辦事項的網頁」。AI 會自己在工作區裡建立檔案、寫程式碼、完成任務。

你不需要懂程式語言，只需要說清楚你想要的結果。


介面二：Agent Manager（代理人控制台）

Agent Manager 是 Antigravity 的第二個核心介面，專門用來監控 AI 正在執行的工作。

當你下達一個比較複雜的任務，AI 可能會同時處理多個步驟：建立資料庫、寫後端邏輯、產生前端畫面……Agent Manager 讓你能看到每個步驟的執行狀態、查看 AI 的執行計畫，也可以在中途暫停或調整方向。

你可以把它想成「任務追蹤面板」——不用去盯著程式碼，只需要看進度、確認結果。


和 Claude Code 的差異

我比較喜歡Claude Code，但本教學使用的Antigravity定位相似，都是 Agent AI 開發工具。主要差異在於：

AntigravityClaude Code
介面圖形介面（類 VS Code）終端機指令列
上手門檻較低，視覺化操作較高，需熟悉終端機
背後模型主要使用 Gemini 3使用 Claude 系列模型
適合對象有 Google 訂閱的使用者習慣指令列的使用者

如果你已經有 Google 訂閱、或是比較習慣圖形介面，Antigravity 是很合理的起點。
