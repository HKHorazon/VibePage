# SyllabusTrack — 設計規格

**日期：** 2026-05-10  
**專案路徑：** `d:\VibePage\SyllabusTrack\`

---

## 概述

給大學教授使用的課程進度追蹤靜態網頁。支援多門課程，每門課自由管理單元清單，以 25% 為單位記錄教學進度，並保存每週教學紀錄。

---

## 技術架構

- Vue 3 ESM（`../framework/vue.esm-browser.js`）
- Tailwind CSS（`../framework/tailwind.min.css`）
- 無後端、無建置工具，純靜態
- 資料全部存 `localStorage`，key 為 `syllabustrack_data`

---

## 資料結構

```json
{
  "courses": [
    {
      "id": "uuid",
      "name": "微積分 I",
      "units": [
        { "id": "uuid", "name": "Ch1 極限", "progress": 100 },
        { "id": "uuid", "name": "Ch2 微分", "progress": 50 }
      ],
      "weeklyLog": [
        {
          "id": "uuid",
          "week": 14,
          "date": "2026-05-06",
          "note": "今天上完極限，學生狀況不錯",
          "changes": [
            { "unitId": "uuid", "unitName": "Ch2 微分", "from": 25, "to": 75 },
            { "unitId": "uuid", "unitName": "Ch3 積分", "from": 0, "to": 25 }
          ]
        }
      ]
    }
  ],
  "activeCourseId": "uuid"
}
```

`progress` 只能是 0、25、50、75、100。`weeklyLog` 只記錄有變動的單元（`from !== to`）。

## 畫面與功能

### 1. 頂部導覽

**桌機（≥ 560px）**
- 左側：課程名稱下拉選單，展開後列出所有課程，底部有「＋ 新增課程」
- 右側：「✏️ 編輯」按鈕進入編輯模式

**手機（< 560px）**
- 左側：漢堡圖示 ☰，點擊開啟側欄
- 中間：當前課程名稱
- 右側：「✏️」圖示進入編輯模式
- 側欄：列出所有課程，點選切換，底部有「＋ 新增課程」，點空白處關閉

---

### 2. 單元進度列表（一般模式 = 本週紀錄模式）

一般模式同時就是本週紀錄狀態，三色即時反映：

| 格子顏色 | 意義 |
|----------|------|
| 灰色 | 尚未教到（進度 = 0 或低於此格） |
| 藍色 | 已在前幾週記錄過的舊進度 |
| 綠色 | 本次新點選、尚未存檔的進度 |

- 每個單元一行，格式：`[單元名稱]　[██▓▓░░]　[75%]`
- 進度條為 4 格（代表 25/50/75/100%），點擊行為：
  - 點第 N 格 → 設為 N×25%
  - 若已是 N×25%，點同格 → 退一格，設為 (N-1)×25%（最低 0%）
  - 例：當前 75%，點第 3 格 → 退為 50%；點第 4 格 → 進為 100%
- 百分比文字：0% 灰色、藍格範圍藍色、含綠格則綠色
- 按「記錄本週」後，綠格轉為藍格（快照更新），本週紀錄存入 weeklyLog
- 底部固定兩個按鈕：「記錄本週」、「週誌」

---

### 3. 記錄本週

- 按下後，比對現在所有單元的 `progress` 與上次記錄時的快照（或初始 0%）
- 若有任何單元有變動：彈出一個小輸入框讓教授填寫本週備註（可空白），確認後建立 weeklyLog 條目，自動計算當前週次（以學期開始日計算，若無設定則用第一筆紀錄日為第 1 週），日期為今天
- 若無任何變動：顯示提示「本週尚無進度變動」
- 記錄後，將當前所有單元的 progress 儲存為「快照基準」（存入 localStorage，key: `syllabustrack_snapshot_{courseId}`）
- 下次「記錄本週」時，以此快照為比對基準；若課程從未記錄過，基準為全部 0%

---

### 4. 週誌 Overlay

- 從底部滑出，佔畫面約 70% 高度
- 標題列：「週誌 — [課程名稱]」，右側 ✕ 關閉
- 標題列下方為週次切換列：`← 第 13 週　第 14 週　第 15 週 →`，左右箭頭切換，當前週高亮
- 內容區（單一週顯示，切換週時內容換頁）：
  - 標題：`第 N 週　YYYY/MM/DD`
  - 若有備註，顯示備註文字（灰色小字，完整呈現）
  - 只顯示有變動的單元，每個單元：
    - 單元名稱 + `from% → to%`（文字）
    - 單條進度條（4 格）：藍格 = from% 已有的格，綠格 = 本週新增的格，灰格 = 未完成
- 打開時預設顯示最新一週
- 無紀錄時顯示「尚無週誌紀錄」

---

### 5. 編輯課程模式

進入後，頂部出現「完成編輯」按鈕，進度條變為不可點擊。

單元列表改為：
- 每列左側：`☰`（拖曳排序）、單元名稱（可點擊改名，inline 文字輸入）、右側 `✕` 刪除
- 最底部：「＋ 新增單元」按鈕，新增後直接 focus 到名稱輸入框

課程管理（在側欄或下拉選單中）：
- 長按或右側鉛筆圖示改名
- 確認後刪除課程（含警告提示）

---

### 6. 學期週次設定

- 在側欄底部或設定區，可輸入「學期開始日期」
- 系統自動計算「今天是第幾週」並在頂部顯示小標（e.g., `第 14 週`）
- 若未設定，不顯示週次，紀錄仍可正常運作（手動週次從 1 開始累加）
